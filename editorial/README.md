# Workspace editoriale

Questo spazio contiene il materiale editoriale che precede la pubblicazione.

## Struttura

### idee/

Idee, spunti e argomenti ancora da sviluppare.

### ricerca/

Fonti, dati, appunti e materiale utilizzato per preparare gli articoli.

## Workflow editoriale

IDEA
↓
RICERCA
↓
BOZZA
↓
REVISIONE
↓
PUBBLICAZIONE

Le bozze degli articoli vengono gestite nella directory `_drafts/`.

Gli articoli pubblicati vengono gestiti nella directory `_posts/`.

## Regola

Non inserire articoli pubblicati direttamente nelle cartelle editoriali.

Il contenuto pubblicato deve terminare in `_posts/` con il formato:

YYYY-MM-DD-titolo.md
